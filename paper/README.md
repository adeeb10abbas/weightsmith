# Distilling Instructions into Weights: Closed-Form Edits Fix a Robot Policy's Misreading

LaTeX sources for the arXiv preprint by Ali-Adeeb Abbas and Esmaeil Seraj (authors and affiliations are still to be
confirmed; see the `TODO` comment next to `\author` in `main.tex`). The compiled paper is `main.pdf`: six pages of
main text, references, and Appendices A–F.

The paper reports the Claude Opus weight-editing cohort on the zero-shot π0.5 DROID policy in RoboLab: closed-form
instruction distillation, which fixes a language-binding failure (held-out 27/128 → 106/128), its 0.16% low-rank
variant, its transfer to other tasks, the failure levels where edits did not help, and the noise floor of paired
closed-loop evaluation. It is separate from the companion Astra study manuscript in `study/paper/`, which it cites.

## Build

Requires a TeX Live installation with `latexmk` and `pdflatex` (TeX Live 2025 was used). The CoRL 2026 style
(`corl_2026.sty`, `corlabbrvnat.bst`) is included.

```
cd paper
make            # latexmk -pdf main.tex  ->  main.pdf
make figures    # python3 scripts/make_figures.py  (numpy, matplotlib, pillow)
./arxiv.sh      # builds arxiv_submission.tar.gz and test-compiles it without BibTeX
```

`arxiv_submission.tar.gz` contains `main.tex`, `main.bbl`, `corl_2026.sty`, `corlabbrvnat.bst`, `generated/*.tex`,
and the PDF figures that `main.tex` includes. It is a build product and is not committed.

## Where the numbers come from

Every number in the paper comes from these repository files. The figures and the large tables are generated by
`scripts/make_figures.py`; the numbers in the text and in the small Tables 2, 3, 5, and 7 are transcribed from the
same sources.

| Source | Used for |
|---|---|
| `study/results/opus/comparisons.json` | Every paired comparison (n, unedited, edited, fixed, broke): Figs. 2–5, Tables 6 and 8–9 |
| `study/results/opus/heldout/*.json` | Held-out runs: per-slot outcomes, Wilson intervals, exact McNemar p, steps to success, Table 10 |
| `study/blog/failure-levels.md` | 16-task survey (Table 4), the flat-box transfer row, replay and ablation tables, diagnosis numbers |
| `study/results/opus/EVIDENCE.md` | Edit construction, budgets, costs, offline attempts, lane check |
| `study/results/opus/claude-astra-protocol-{BRIEF,FINAL}.md` | The Claude-under-Astra-protocol run (Appendix D) |
| `study/RESULTS.md`, `study/blog/draft.md` | Companion Astra study results that the paper cites |
| `study/review/guo-xie.md`, `study/blog/recent_work_table.md` | Others' reported results (not reproduced) |

Statistics: paired 95% intervals are bootstrap intervals over the four paired outcome types (20,000 multinomial draws,
seed 0), as in `study/results/scripts/plot_opus_forest.py`; the pooled gripper row is resampled within each task;
p-values are exact two-sided McNemar tests; minimum detectable effects use the normal approximation with 30%
discordant pairs, 80% power, and two-sided α = 0.05. `make_figures.py` asserts that the held-out per-slot outcomes
reproduce every held-out summary and that the JSON rows match the held-out files.

Table 1 frames: frame 210 (t = 7.0 s) of the side-by-side clip of held-out slot 90000, committed on the `site/v1`
branch as `site/assets/video/cube_then_banana.mp4` (unedited above, edited below; wrist camera). To regenerate:

```
git show site/v1:site/assets/video/cube_then_banana.mp4 > /tmp/cube_then_banana.mp4
python3 paper/scripts/extract_teaser_frame.py /tmp/cube_then_banana.mp4
```

Figure style follows the authors' earlier preprint (arXiv:2610.16242): DejaVu Sans, teal `#147D92` for the
distilled edit, orange `#C46635` for GPT-6 Astra, purple `#7856A5` for other Claude Opus edits, and gray for runs
without a weight change.
