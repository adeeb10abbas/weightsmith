# Distilling Instructions into Weights: Closed-Form Edits Fix a Robot Policy's Misreading

LaTeX sources for the arXiv preprint by Ali-Adeeb Abbas and Esmaeil Seraj (authors and affiliations are still to be
confirmed; see the `TODO` comment next to `\author` in `main.tex`). The compiled paper is `main.pdf`: six pages of
main text, references, and Appendices A–F.

The paper reports the Claude Opus weight-editing cohort on the zero-shot π0.5 DROID policy in RoboLab: closed-form
instruction distillation, which fixes a language-binding failure (held-out 27/128 → 106/128), its 0.16% low-rank
variant, its transfer to other tasks, the failure levels where edits did not help, and the noise floor of paired
closed-loop evaluation. It is separate from the companion Astra study manuscript in `study/paper/`, which it cites.

## Build

Requires a TeX Live installation with `latexmk` and `pdflatex` (TeX Live 2025 was used). The CoRL 2026 style
(`corl_2026.sty`, `corlabbrvnat.bst`) is included.

```
cd paper
make            # latexmk -pdf main.tex  ->  main.pdf
make figures    # python3 scripts/make_figures.py  (numpy, matplotlib, pillow; figures use Arial)
./arxiv.sh      # builds arxiv_submission.tar.gz and test-compiles it without BibTeX
```

`arxiv_submission.tar.gz` contains `main.tex`, `main.bbl`, `corl_2026.sty`, `corlabbrvnat.bst`, `generated/*.tex`,
and the PDF figures that `main.tex` includes. It is a build product and is not committed.

## Where the numbers come from

Every number in the paper comes from these files. The figures and the large tables are generated by
`scripts/make_figures.py`; numbers in the text and the small tables are transcribed from the same sources.

| Source | Used for |
|---|---|
| `study/results/opus/comparisons.json` | Every paired comparison (n, unedited, edited, fixed, broke): Figs. 3–5, Tables 3, 6 and 7 |
| `study/results/opus/heldout/*.json` | Held-out runs: per-slot outcomes, Wilson intervals, exact McNemar p, steps to success, Table 8 |
| `study/blog/failure-levels.md` | 16-task survey (Table 1), flat-box transfer row, replays and ablations (Fig. 2, Table 5), diagnosis numbers |
| `study/results/opus/EVIDENCE.md`, `study/results/opus/ctb/README.md` | Edit construction, offline attempts (Fig. 2b), budgets, costs, lane check |
| `study/results/opus/claude-astra-protocol-{BRIEF,FINAL}.md` | The Claude-under-Astra-protocol run (Appendix D) |
| `study/RESULTS.md`, `study/blog/draft.md` | Companion Astra study results that the paper cites |
| `study/review/guo-xie.md`, `study/blog/recent_work_table.md` | Others' reported results (not reproduced) |
| `paper/figures/src/*` | Per-episode data from the GPU host (below) |

Statistics: paired 95% intervals are bootstrap intervals over the four paired outcome types (20,000 multinomial draws,
seed 0), as in `study/results/scripts/plot_opus_forest.py`; the pooled gripper row is resampled within each task;
p-values are exact two-sided McNemar tests; minimum detectable effects use (z₀.₉₇₅ + z₀.₈)·√(q/n) with q = 0.3
discordant pairs (band 0.2–0.4). `make_figures.py` asserts that the held-out per-slot outcomes reproduce every
held-out summary, that the JSON rows match the held-out files, that the event summary matches the held-out outcomes
slot by slot, and that slot 90002 is the one the Fig. 1 rule picks.

## Per-episode data from the GPU host

Fig. 1 and the cube-drop counts use recorded episodes of the held-out run
`projects/cube-then-banana/heldout/v2mi-f-RubiksCubeThenBananaTask-90000-128/` on the GPU host. Each `logs-{base,cand}-*/rows.json`
lists, per slot, the episode's observation file (`obs-*/obs_r0_e*.npz`: camera inputs and the 15×8 action chunk of every
replan) and its RoboLab event log. The committed files in `figures/src/` were built from them:

```
# Fig. 1 (slot 90002 = env 2 of lane 0 in the first half): copy obs + log for both arms into SRC/{base,cand}/
python3 paper/scripts/build_teaser_data.py SRC
# event summary: the four rows.json files into ROWS/ and the 256 logs they list into logs.tgz
python3 paper/scripts/summarize_heldout_events.py ROWS logs.tgz
```

Fig. 1 shows the lowest-numbered held-out slot that the edit fixed and whose unedited run dropped the cube outside the
bowl before touching the banana. A cube drop is a `TARGET_OBJECT_DROPPED` event with an `OBJECT_GRABBED_FAILURE` for
the cube at the same step and no container success within two steps.

## Style

Neutral greys with one accent: teal `#147D92` for the distilled edit, a muted red `#B1504A` only for broken pairs and
the dropped cube, Arial at 6–7 pt, thin rules, and direct labels instead of legends. Figures are drawn at the 5.5 in
text width.
